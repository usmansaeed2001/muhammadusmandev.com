02 · AAI Innovations

MCP Gateway

The layer that lets customers plug specific product features into their own AI agents, without buying the full product.

  • One gateway hosts 5 MCP servers over the full Streamable HTTP protocol, working with clients like Claude and Cursor.
  • OAuth 2.1 with Client ID Metadata Documents (CIMD), which replaces Dynamic Client Registration, plus per-request authorization.
  • Tracks credit usage per user and routes each request to the existing product services, returning results to the agent.
